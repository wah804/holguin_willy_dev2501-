# Willy Holguin

## DEV2501-O 01
**Assignment:** 01_Components (Reusable Component Library)

This project is a one page React application that demonstrates reusable components using **CSS-in-JS** (`styled-components`) and **dynamic props**.

## Project Rules
- **No `useState`** (stateless UI)
- **CSS-in-JS only** (styled-components inside each component)
- **Dynamic text via props** (no hardcoded UI text)
- **Only allowed library:** `styled-components`
- **React Icons** used where required (search/settings/edit/delete)

## Components Included
- **Button** (reusable, hover styles)
- **Form** (post title + post description inputs)
- **Header** (logo, search w/ icon, avatar + settings icons)
- **LeftNavigation** (Newsfeed, Messages, Watch)
- **AdCard** (image, title, subtitle via props) ×2
- **PostCard** (avatar, title, description, edit/delete icons)

## Branch Guide
- **dev**  
  Ongoing development branch for the month.

- **01_Components**  
  Submission branch. Contains the reusable components listed above and the one page layout displayed in `App.jsx`.

## How to Run
### 1) Install dependencies

   **npm install**

### 2) Start server

   **npm run dev**
